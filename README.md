# Event Registration System

An interactive web-based Event Registration System built using **HTML, CSS, and JavaScript**.

The application allows users to register for an event, view registered participants, search participants, edit registration details, delete registrations, and track available seats.

# Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

# Features

- User-friendly event registration form
- Participant registration
- Name, email, phone, city, profession, and session details
- Email validation
- 10-digit phone number validation
- Duplicate email prevention
- Maximum seat limit of 200 participants
- Available seat counter
- Seat progress bar
- Registered participant list
- Search participants
- Edit participant information
- Delete participant registration
- Registration success message
- LocalStorage for saving registration data
- Responsive design for desktop, tablet, and mobile devices
